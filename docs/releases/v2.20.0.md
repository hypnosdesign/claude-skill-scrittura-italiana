# v2.20.0 — marketplace Claude Code

Scrittura italiana si installa anche come plugin da un marketplace ospitato nello
stesso repository. Le istruzioni editoriali e i nove riferimenti sono quelli della
2.19.2; cambia soltanto la versione nel frontmatter della skill.

## Installazione in Claude Code

Esegui dentro Claude Code:

```text
/plugin marketplace add hypnosdesign/claude-skill-scrittura-italiana
/plugin install scrittura-italiana@scrittura-italiana
```

Riapri Claude Code dopo l'installazione. Puoi invocare la skill con
`/scrittura-italiana:scrittura-italiana`.
Se passi da una copia installata con Git o `npx skills`, rimuovi quella copia per
evitare che Claude Code carichi due volte la skill.

Per gli aggiornamenti automatici, apri `/plugin` → **Marketplaces**, seleziona
`scrittura-italiana` e abilita **Enable auto-update**. Per questo marketplace
l'opzione è disattivata per impostazione predefinita. Le nuove release incrementano
la versione del plugin per aggiornare la copia in cache.

## Altri client

Per Claude Desktop e claude.ai scarica **`scrittura-italiana-2.20.0.zip`** dagli
allegati: contiene un solo `SKILL.md` e i nove riferimenti. I manifest del plugin
restano nel repository e non sono inclusi nello ZIP della skill.

Restano disponibili l'installazione tramite `npx skills`, la copia manuale con Git
e la [versione in un solo file](https://github.com/hypnosdesign/claude-skill-scrittura-italiana/blob/v2.20.0/scrittura-italiana-single-file.md).
