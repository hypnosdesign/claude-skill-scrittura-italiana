# v2.21.0 — voce d'autore e testi autonomi

Tre aggiunte alla skill, sviluppate con istruzioni, esempi e codice originali:

- **Scheda di voce riutilizzabile:** distingue osservazioni documentate, misure
  effettive e preferenze richieste; separa registri diversi e circoscrive le
  conclusioni ricavate da campioni brevi.
- **Misuratore locale facoltativo:** con Node.js 22 o successivo descrive campioni
  e bozze in JSON. Misura lunghezze, punteggiatura e ricorrenze; non modifica i file
  e non assegna punteggi di qualità o autorialità.
- **Autonomia del testo pubblicabile:** verifica che il documento sia comprensibile
  senza la chat, usando solo informazioni disponibili e rispettando il livello
  di revisione richiesto.

Il pacchetto **`scrittura-italiana-2.21.0.zip`** contiene un solo `SKILL.md`, dieci
riferimenti e il misuratore. La versione monofile contiene tutte le istruzioni;
le misure richiedono lo script separato e un ambiente di esecuzione.

## Installazione e aggiornamenti

Dentro Claude Code:

```text
/plugin marketplace add hypnosdesign/claude-skill-scrittura-italiana
/plugin install scrittura-italiana@scrittura-italiana
```

Per gli aggiornamenti automatici: `/plugin` → **Marketplaces** →
**scrittura-italiana** → **Enable auto-update**. Riapri Claude Code per caricare
la versione aggiornata. Per aggiornare manualmente, dal terminale:

```bash
claude plugin marketplace update scrittura-italiana
claude plugin update scrittura-italiana@scrittura-italiana
```

Per gli agenti compatibili con il CLI di skills.sh:

```bash
npx skills add hypnosdesign/claude-skill-scrittura-italiana
npx skills update scrittura-italiana
```

Gli aggiornamenti con `npx skills` sono manuali; `update` senza un nome aggiorna
tutte le skill gestite dal CLI. Evita di installare la stessa skill due volte nello
stesso agente. Per Claude Desktop e claude.ai usa lo ZIP allegato alla release.

## Verifiche e limiti

- Test deterministici del misuratore e del pacchetto, inclusa l'esecuzione dello
  script estratto dallo ZIP.
- Versioni, manifest del plugin, sito e versione monofile verificati.
- Nove casi editoriali di sviluppo e due casi di instradamento aggiunti; i casi
  precedenti e i sei held-out sono invariati.
- Tre prove d'uso indipendenti: scheda di voce, avviso autonomo e confronto locale.

I nuovi casi editoriali non sono stati sottoposti a un benchmark completo con i
modelli. Le prove d'uso e i test deterministici non costituiscono una misura
generale della qualità di scrittura. L'audit di settembre resta aperto.
