Installazione rapida

Se hai Node installato, il comando seguente rileva gli agenti compatibili presenti sul computer.

npx skills add hypnosdesign/claude-skill-scrittura-italiana

Controlla sempre la destinazione proposta dal comando prima di confermare.

Claude Code

Marketplace (consigliato per Claude Code)

Esegui questi due comandi dentro Claude Code, poi riapri la sessione.

/plugin marketplace add hypnosdesign/claude-skill-scrittura-italiana
/plugin install scrittura-italiana@scrittura-italiana

Il marketplace e il plugin si chiamano entrambi scrittura-italiana. Puoi invocare la skill con /scrittura-italiana:scrittura-italiana. Se passi al plugin da una copia installata con Git o npx skills, rimuovi quella copia per evitare che la skill venga caricata due volte.

Installazione manuale in tutti i progetti

git clone https://github.com/hypnosdesign/claude-skill-scrittura-italiana ~/.claude/skills/scrittura-italiana

Disponibile in un solo progetto

Clona la repository in .claude/skills/scrittura-italiana nella radice del progetto. Riapri Claude Code dopo l'installazione.

Come si attiva

La descrizione della skill intercetta richieste di scrittura, correzione, revisione, argomentazione e dubbi sulla lingua italiana. Puoi anche nominarla esplicitamente.

Claude Desktop e claude.ai

  1. Scarica il pacchetto scrittura-italiana-<versione>.zip dagli asset dell'ultima release. ⚠ Non usare Code, Download ZIP: quello ZIP contiene l'intero repository e il caricamento lo rifiuta.
  2. Apri Impostazioni, Capabilities, Skills.
  3. Carica la cartella o il file ZIP.

La disponibilità delle Skill e dell'esecuzione di codice dipende dal client e dal piano. Se la voce non compare, consulta la documentazione aggiornata del servizio.

GPT, Qwen, DeepSeek e altri LLM

Il modello e l’interfaccia sono due scelte distinte. Se il tuo agente supporta Agent Skills, installa la cartella con npx skills add. In una chat o in un ambiente che accetta istruzioni e documenti, usa la versione monofile.

  1. Scarica il file Markdown completo dal collegamento qui sotto.
  2. Caricalo come documento di riferimento oppure forniscilo come istruzioni, entro il contesto disponibile.
  3. Chiedi di applicare la skill Scrittura italiana e indica il livello di revisione: proofread, line edit o deep rewrite.
  4. Fornisci il testo, il destinatario e i vincoli. Per lavori successivi, conserva il file nell’ambiente che stai usando.

Le regole editoriali sono comuni ai modelli; attivazione automatica, lettura dei file ed esecuzione del misuratore dipendono dall’interfaccia. Le prove con Claude e GPT documentano i risultati osservati, senza estenderli ai modelli non valutati.

Apri la versione in un solo file

Limite della versione singola

Il contenuto resta disponibile, ma si perde l'attivazione automatica e il caricamento progressivo dei riferimenti. Il prompt completo è inoltre più pesante.

Come usarla

Indica l'obiettivo e, quando conta, il livello d'intervento. Incolla poi il testo completo e specifica eventuali vincoli.

Correzione minima

Esegui un proofread. Correggi soltanto errori grammaticali e di punteggiatura. Non modificare lessico o struttura.

Revisione della tesi

Esegui un line edit conservativo di questo paragrafo. Migliora chiarezza e ritmo, ma conserva tesi, negazioni, grado di certezza e terminologia.

Riscrittura profonda

Riscrivi il testo in modo più naturale. Non aggiungere dati o esempi. Segnala separatamente le informazioni concrete che mancano.

Con un campione di voce

Usa il secondo testo come campione del mio stile. Revisiona il primo senza copiarne le frasi e senza aggiungere opinioni.

Per testi lunghi, lavora per capitoli e conserva un glossario di nomi, concetti e scelte terminologiche.

Aggiornare la skill

Plugin dal marketplace

Per ricevere aggiornamenti automatici, apri /plugin, vai in Marketplaces, seleziona scrittura-italiana e abilita Enable auto-update. Per i marketplace aggiunti dall'utente, l'opzione è disattivata per impostazione predefinita.

Per aggiornare manualmente, esegui questi comandi nel terminale e riapri Claude Code:

claude plugin marketplace update scrittura-italiana
claude plugin update scrittura-italiana@scrittura-italiana

Vedi la documentazione sugli aggiornamenti di Claude Code.

Installazione con npx skills

Aggiorna questa skill con il CLI di skills.sh. Gli aggiornamenti sono manuali; senza il nome della skill, npx skills update aggiorna tutte le skill gestite dal CLI.

npx skills update scrittura-italiana

Copia installata con Git

Se l'hai clonata con Git, entra nella cartella della skill ed esegui:

git pull --ff-only

Prima di aggiornare una copia modificata localmente, controlla git status e conserva le personalizzazioni. Le note di rilascio sono nel CHANGELOG.
